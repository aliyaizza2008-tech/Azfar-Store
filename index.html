Cara upload ke GitHub Pages (bisa dari HP):

  1. Daftar atau login di github.com.
  2. Ketuk + → New repository. Isi namanya (misalnya milyardigi), pilih Public, lalu Create repository.
  3. Ketuk uploading an existing file, pilih index.html, lalu Commit changes.
